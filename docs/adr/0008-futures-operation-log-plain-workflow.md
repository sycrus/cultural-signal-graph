# Futures: an operation log as source of truth, a plain workflow instead of LangGraph

Each exploration is an append-only operation log (`runs/<run>/explorations/<id>/log.jsonl`); its state is the log replayed up to a cursor. Generation operations embed the full model input and raw output. One mechanism therefore delivers undo/redo (move the cursor; redo replays stored output with no model call), provenance (every projection points at the op that made it), stale propagation (computed on replay), and export (the log is the file). The generator is a plain Python loop — one call per order, a cancel flag checked between orders — rather than a LangGraph graph: LangGraph earned its place in the forecast pipeline through `interrupt()` for the sign-off gate (ADR-0001), and futures mode has no gate, while the log already does the checkpointing. The only agentic step, "Ground this", reuses discovery's bounded search.

**Considered options:** LangGraph for consistency with ADR-0001 (rejected — a second checkpointer alongside the log, and no interrupt to justify it); snapshot-per-change storage (rejected — simpler, but gives neither provenance of model I/O nor free redo); storing projections only as RDF triples (rejected — RDF can't cheaply hold the ordered history undo needs; the graph is a materialization of the log instead).
